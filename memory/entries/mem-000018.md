The Ink TUI has several rendering constraints: (1) 120-entry transcript buffer to bound memory. (2) Responsive layout with 140-col breakpoint — left pane 26-32 chars, right 32-38 chars. (3) Polling deferred when user has focus on composer with non-empty draft to prevent visual jitter. (4) Connection retry: 2s (stream end), 3s (stream error), 5s (connection error). (5) InlineTextInput scrolls horizontally to keep cursor visible, filters Tab/Escape/Up/Down for parent focus management. (6) User runs TUI in cmd.exe (not Windows Terminal) so design for its rendering limits.
