The orchestrator maintains ONE long-lived Copilot SDK session across all conversations and channels. Session ID is persisted to SQLite so it survives daemon restarts. Alternatives considered: per-conversation sessions (rejected — loses cross-channel context), per-channel sessions (rejected — SDK sessions are heavyweight ~400MB). Trade-off: model switching requires session invalidation and recreation since SDK doesn't support mid-session model changes.
