Daemon restart spawns a detached child process with ATTACHE_RESTARTED=1 env var, then the parent exits. Detached spawn ensures the child survives parent death. The child detects the env var on startup and sends a 'back online' notification to Telegram. Restart is scheduled 1 second after the current response is delivered to give time for response delivery. Triggered by restart_attache() tool or POST /restart (500ms delay).
