Workers are dispatched non-blocking — create_worker_session and send_to_worker return acknowledgment immediately while work runs in background. Results feed back via feedBackgroundResult() which re-enters the orchestrator queue as a system message. Workers auto-destroy after each task completion (~400MB freed per session). Max 5 concurrent workers enforced to prevent resource exhaustion. Each worker runs with approveAll=true (no interactive permission prompts).
