By default (ATTACHE_SELF_EDIT disabled), the orchestrator system message includes a large warning block prohibiting workers from modifying Attache source code. Only user project files, local skills, user .env, and external files are allowed. Must start daemon with --self-edit flag (sets ATTACHE_SELF_EDIT=1) to remove this restriction. The CLI flag is processed in src/cli.ts before daemon import.
