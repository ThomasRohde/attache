The daemon prioritizes staying alive: (1) Orchestrator retries 3x with exponential backoff (1s, 3s, 10s) for transient errors (timeout, disconnect, EPIPE, ECONNRESET). (2) Fatal session errors (closed/destroyed/disposed/invalid/expired) trigger session invalidation for recreation. (3) Health check every 30s detects dead client, triggers client reset + session invalidation. (4) Classifier failure falls back to 'standard' tier. (5) Response delivered to user FIRST, logging is best-effort. (6) Unhandled rejections logged but don't crash. (7) Skill/memory load failures continue without those features.
