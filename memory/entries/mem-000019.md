npm package includes compiled JS (dist/), bundled skills (skills/), and pre-built AttacheShell.exe (shell/dist-win/). CI workflow (.github/workflows/build-shell.yml) auto-builds the .NET tray app on shell/ changes and commits the exe back to repo. postinstall.js copies AttacheShell.exe to %LOCALAPPDATA%/Programs/attache-shell/ on Windows. Global install via 'npm install -g attache' delivers daemon + shell + skills in one step. Package type is ES modules.
