Workers are blocked from operating in directories containing credentials: .ssh, .gnupg, .aws, .azure, .kube, .docker, .npmrc, and similar. Path traversal protection uses path.resolve() comparison to prevent bypasses like '../.ssh'. Workers run with full tool approval (approveAll) so this directory-level block is the primary safety mechanism.
