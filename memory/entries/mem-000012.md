When the router decides to switch models, the orchestrator session is set to undefined and its session ID deleted from DB. The switch doesn't happen mid-message — it takes effect on the NEXT message when resolveModel() detects the change. This means a model switch always causes a brief context recovery (last 10 turns re-injected). The classifier session (GPT-4.1) is separate and stateless — destroyed on error, recreated on next classification.
