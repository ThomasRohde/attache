The C# tray app tries three strategies to find and launch the daemon: (1) PATH lookup — runs 'cmd.exe /c attache start', uses where.exe to find attache.cmd, augments PATH with %APPDATA%/npm if needed. (2) Global npm install — directly runs 'node %APPDATA%/npm/node_modules/attache/dist/cli.js start'. (3) Dev/from-source — walks up 8 directory levels from exe to find dist/cli.js in repo. All strategies use CreateNoWindow=true and entireProcessTree=true for clean kill. Terminal launcher tries Windows Terminal (wt.exe) first, falls back to cmd.exe.
