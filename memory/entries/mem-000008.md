API authentication uses a single bearer token generated at first daemon startup and stored in ~/.attache/api-token with filesystem mode 0o600 (owner-read-only). Token is re-read from file on each API client call (daemon may create between attempts). Only /status endpoint is unauthenticated (used for health checks). No CORS headers since API is localhost-only (127.0.0.1).
