The original Ink-based terminal TUI was fully replaced by a .NET 10 Blazor Hybrid desktop app (AttacheGui). WinForms host with BlazorWebView, 4-pane layout (workers/transcript/inspector/composer), Markdig markdown rendering, system tray integration, setup wizard, SSE streaming.
