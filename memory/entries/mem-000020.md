Database schema changes use a manual migration pattern in db.ts: detect missing column/constraint via try/catch or schema introspection, then migrate by renaming old table, creating new one with correct schema, copying data, dropping old. Example: conversation_log migration added 'system' to the role CHECK constraint. No migration framework — all inline. WAL mode enabled for concurrent reads during writes.
