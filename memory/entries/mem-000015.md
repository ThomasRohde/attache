SSE events use schema version 1 with four event types: session.connected (connectionId), orchestrator.message.delta (streaming chunk), orchestrator.message.complete (final text + routing metadata), orchestrator.message.cancelled. Events have both new names and legacy 'type' field for backwards compat. Routing metadata (model, tier, routerMode, overrideName) only attached to .complete events. Envelope uses spread pattern — data fields duplicated at root level for old clients.
