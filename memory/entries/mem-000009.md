Daemon shutdown uses a three-state machine: idle → warned → shutting_down. First Ctrl+C with active workers shows a warning and moves to 'warned'. Second Ctrl+C force-exits. A 3-second timeout force-exits regardless. Shutdown sequence: stop Telegram bot → destroy all workers (Promise.allSettled) → clear worker map → stop Copilot client → close SQLite → exit(0). Unhandled rejections log but keep daemon alive; uncaught exceptions trigger immediate shutdown.
