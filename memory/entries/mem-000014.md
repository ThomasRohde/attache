Messages are tagged with source channel: [via telegram] or [via tui]. The orchestrator system message instructs different response styles per channel — Telegram: brief (mobile), TUI: detailed (terminal), Background: relay results. Workers inherit originChannel so background task completions route back to the originating channel via proactiveNotifyFn. Channel tags are stripped before classification to prevent the router from being biased by channel.
